# 项目价值与未来方向

> 2026-07-13 | 讨论记录

---

## 一、当前价值

### 1. 学习资产

- 中文 MLIR 实战全记录，国内几乎找不到第二个
- 10+ 份文档（项目设计、进度管理、异常记录、总结报告、多份对比分析）
- 20+ 次提交，每次有实际产出和决策记录
- 对面试 AI 编译器/大模型推理岗是直接材料

### 2. 基础设施

```
已验证可用的 pipeline:
  PyTorch → torch-mlir → Linalg → GPU kernel → (等 NVPTX)
                        ↓
                  自定义 Pass ← CountLinalgOps (可扩展)
                        ↓
                  IREE CPU 执行 (功能验证)
                        ↓
                  Triton 4060 (性能对比基线)
```

这整套管线可以测试任何优化想法，不用每次从零搭。

### 3. 差异化

市场上 MLIR 人才少，能同时做 MLIR Pass + Triton kernel 的人更少。有能力从图优化一直看到 GPU kernel 执行。

## 二、发展点

### 短期 (1-2 周)

| 方向 | 产出 | 价值 |
|------|------|------|
| **Triton 融合 kernel** | GELU+add+mul 单 kernel vs 多 kernel 基准 | 证明融合优化的实际加速比 |
| **Linalg→PTX 闭环** | NVPTX rebuild 完后跑实际 GPU kernel | 完成完整链路 |
| **多模型验证** | Qwen 2.5 1.5B 导出 + 优化对比 | 验证泛化性 |

### 中期 (1 个月)

| 方向 | 产出 | 价值 |
|------|------|------|
| **FuseLayerNorm Pass** | 第二个自定义 Pass，做真实 IR 变换 | 面试可说的融合 Pass 经验 |
| **三方基准报告** | MLIR GPU vs Triton vs PyTorch 对比 | 有数据支撑的结论 |
| **技术博客** | 三篇系列文章（导出→优化→GPU） | 个人品牌 |

### 长期

| 方向 | 产出 | 价值 |
|------|------|------|
| **给 torch-mlir 提 PR** | 修复缺失 op 分解或新增 lowering | 开源贡献 |
| **扩展到 TVM/MLIR** | 学习 TVM auto-tuning vs MLIR 手动 tiling | 技术栈宽度 |
| **量化 + 编译融合** | FP8 量化 + MLIR kernel 融合叠加 | 工业热点 |
