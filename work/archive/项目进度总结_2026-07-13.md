## 一、项目概况

验证 MLIR 编译器优化对 PyTorch 模型推理加速效果的研究项目。分三阶段：

| 阶段 | 范围 | 状态 | 核心结论 |
|------|------|:---:|------|
| 阶段一 (W0~W5) | 简单模型 | ✅ | 平均 linalg op 降低 25.8% |
| 阶段二 (W6~W8) | GPT-2 | ✅ | 标准 GPT-2 降低 58.5%，规模递增效应 |

## 三、已完成工作

### 阶段一：简单模型

- 3 个模型 (linear_relu/conv_bn_relu/two_layer_mlp) 导出 + lowering
- 最优 Pass: `linalg-fuse-elementwise-ops + canonicalize + cse`
- 平均 op 降低 25.8%，最佳 50% (add_relu)

### 阶段二：GPT-2

- 极小 GPT-2 (2层): linalg ops 降低 52.3%
- 标准 GPT-2 (12层/124M): linalg ops 降低 58.5%
- 发现规模递增效应：模型越大优化效果越显著
- **0 个 torch.operator 兜底** — 所有算子被默认分解表自动处理

## 四、关键路径

### Linalg → GPU 全链路 (已打通)

```
Linalg IR → bufferize → parallel-loops → gpu-map → gpu-convert → kernel-outline
                                                                        ↓
                                                                 gpu.func (832 kernel)
                                                                        ↓
                                                            convert-gpu-to-nvvm
                                                                        ↓
                                                                 PTX/cubin
```

### Transform dialect tiling (已修正)

```
transform.structured.tile_using_for matmul tile_sizes [32, 32, 16]
  → 3 嵌套 scf.for (M:4, N:2, K:16 tiles)
  → bufferize → parallel → GPU
```

### 自定义 Pass 开发

```
CountLinalgOps.cpp → CMake → libCountLinalgOps.so
  → mlir-opt --load-pass-plugin=./lib.so --pass-pipeline='...'
```
